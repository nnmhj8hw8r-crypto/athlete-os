# Известные ограничения и незавершённые функции (v0.1)

## Данные и устройства

- **Данные хранятся только в браузере одного устройства.** Синхронизации нет. Очистка данных сайта,
  удаление PWA или нехватка места могут удалить записи. Единственная защита — регулярный экспорт копии.
- Safari может удалить данные сайта, который давно не открывался (особенно если он не добавлен на экран
  «Домой»). Кнопка «Попросить браузер не удалять данные» в настройках — просьба, не гарантия.
- Телефон и компьютер — разные хранилища; перенос только через файл копии.

## Телефон без HTTPS (локальный запуск; на GitHub Pages не относится)

- По адресу `http://<IP компьютера>` Service Worker не работает: без сети приложение на телефоне не
  откроется. Камера для штрихкода тоже недоступна. Нужен HTTPS (см. ROADMAP, этап 1).
- Офлайн-режим проверен только в Chromium на компьютере (localhost) при остановленном сервере; на iPhone
  не проверялся.

## GitHub Pages и Open Food Facts (v0.2)

- На Pages нет сервера: Perek.us и поиск продуктов по названию недоступны, только штрихкод (OFF).
- Российских товаров в Open Food Facts меньше, чем в Perek.us; данные вносят участники и могут быть
  неточными — сверяйте с упаковкой перед сохранением.
- Установка на iPhone, офлайн-режим и камера на Pages ещё не проверялись на реальном телефоне;
  офлайн по пути `/athlete-os/` проверен в Chromium на компьютере.
- Репозиторий для Pages публичный: код виден всем (данных дневника в нём нет).

## Питание v0.4

- Офлайн-база российских товаров небольшая: 3 062 из ~37 тыс. российских товаров Open Food Facts —
  у остальных участники не внесли пищевую ценность. Для них сканирование открывает форму с названием.
- Базу OFF нужно пересобирать вручную (`scripts/build-off-russia.py` по свежей выгрузке ~1,2 ГБ).
- Типовые блюда — оценка по рецепту из американских ингредиентов, без соли (натрий занижен), реальное
  блюдо в столовой может заметно отличаться.
- Расширенные нутриенты есть не у всех продуктов: старые записи (до v0.4) их не содержат, у товаров OFF —
  только то, что указано на карточке. Статистика показывает покрытие, а не нули.
- Расчёт личного плана — оценка по формулам; ≈7700 ккал/кг особенно неточно на коротких сроках (вода, гликоген).
- Поиск по названию в Open Food Facts онлайн из браузера недоступен (CORS): ищется только офлайн-подмножество.
- На iPhone интерфейс v0.4 не проверялся; проверен в Chromium с эмуляцией 375×812.

## Справочник продуктов (v0.3)

- Справочник USDA описывает американские продукты: «творог», «кефир», «сметана» — ближайшие аналоги
  (cottage cheese, lowfat kefir, sour cream), жирность может отличаться от российских. Для точности —
  продукт с упаковки (штрихкод или ручной ввод).
- Значения у напитков (молоко, сок, кола) — на 100 г, а не на 100 мл.
- Пока 150 продуктов; готовых блюд столовой («плов», «борщ») нет — их можно собрать рецептом.

## Perek.us

- Не проверено с настоящим ключом: ключа нет. Формат ответа по штрихкоду в документации не показан —
  разбор сделан с запасом, но реальный ответ может отличаться. При первом подключении ключа стоит
  проверить вручную (см. TESTING.md).
- Кэш и лимит запросов сервера хранятся в памяти и сбрасываются при перезапуске.
- Бесплатный тариф: 50 карточек/штрихкодов в день, только некоммерческое использование.

## Интерфейс

- Сканирование камерой не проверялось на устройстве.
- На экранах уже 360 px подпись «Тренировки» в нижнем меню может сокращаться многоточием.
- Записи тренировок: упражнение заносится в справочник при сохранении, даже если сохранение тренировки
  затем не прошло проверку (остаётся неиспользуемое название).
- Нет поиска и фильтров по истории тренировок и сна; длинная история показывается целиком.
- Нет отдельного редактирования справочника упражнений (переименование, удаление).
- Прошедшие соревнования не переводятся в статус «Завершено» автоматически — это делает пользователь.

## Разработка

- Сборка выводит предупреждения Rollup о комментариях внутри zod — безвредны.
- `npm install` предупреждает, что install-скрипт esbuild не одобрен (npm 11, allowScripts); сборка
  и тесты при этом работают.
- Сервер требует Node.js ≥ 22.18 (встроенный запуск TypeScript).
