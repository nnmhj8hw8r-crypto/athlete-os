# Требования к продукту — Personal Athlete OS v0.1

## Назначение

Личное приложение одного спортсмена (дзюдо и самбо) для ежедневного учёта подготовки. Главный принцип —
функциональность и надёжность, а не демонстрация технологий. Рабочее название может измениться.

## Параметры

| Параметр | Значение |
|---|---|
| Язык интерфейса | русский |
| Регион продуктов и соревнований | Россия |
| Часовой пояс | `Europe/Moscow` (`src/config.ts`) |
| Дзюдо | категория по умолчанию −73 кг |
| Самбо | категория по умолчанию −71 кг |
| Пользователи | один человек, без аккаунтов |
| Бюджет | без обязательных платных сервисов |

## Реализовано в v0.1

**Главная** (v0.6, по образцу Lift Card) — сводка без кнопок добавления: ближайший старт крупным отсчётом
(взвешивание, цель по весу, сейчас, до цели), масса тела с графиком 30/90 дней/всё и изменением за неделю,
сон и самочувствие (последняя ночь, графики за 2 недели / 30 / 90 дней), питание сегодня, последние
тренировки. Только реальные локальные данные; при их отсутствии — подсказки.

**Главная — виджеты** (v0.7) — кнопка «Настроить главную» (карандаш): включить/выключить виджет, переместить
вверх/вниз, выбрать период графика (масса тела 30/90 дней/всё; сон и самочувствие 2 нед/30/90 дней), «Сбросить».
Виджеты: ближайший старт, масса тела, время в постели, самочувствие, записи сна за 14 дней (по умолчанию
выключен), питание сегодня, последние тренировки. Период, выбранный прямо в карточке, тоже запоминается.

**Вид графиков** (v0.7) — плавные (монотонная кривая, не выходит за реальные значения) или прямые линии,
переключатель в «Настроить главную» и в «Ещё → Настройки»; под линией мягкая заливка.

**Нижняя панель** (v0.7, по образцу пользователя) — плавающая скруглённая «таблетка» с пятью разделами
(значки без подписей, скользящая подсветка активного) и отдельная круглая кнопка «Ещё»; полупрозрачная с
размытием. Приёмы пищи — свои значки в цветных кругах вместо эмодзи. Все элементы скруглены сильнее.

**Оформление** (v0.6) — чёрно-белая тема по настройке телефона: в тёмном режиме чёрный фон и белые
элементы, в светлом — наоборот; цвет только для смысла (зелёный — выполнено, красный — ошибка, цвет
программы — выбор пользователя). Плавные переходы: появление страницы и вкладки, окна выезжают снизу,
отклик на нажатие; при «уменьшении движения» в настройках телефона анимации отключаются.

**Питание** (v0.4 — по скриншотам FatSecret пользователя; этап 1 плана «Питание → Тренировки → Восстановление → Сезон»)
- Дневник: полоса недели (дни с записями отмечены), итоги «Жиры / Углев / Белк / РСК / Калории» (РСК — % от
  цели калорий личного плана, «из …» — цели), плашки «Завтрак / Обед / Ужин / Перекус». Тап по всей плашке
  открывает шторку добавления. Записи: тап — правка, корзина — удаление. Карточка «Вода».
- Шторка: поиск, «Сканирование штрихкода», «Ручной ввод продукта», «Быстрый ввод калорий» (без продукта),
  «Моя сохранённая еда», «Моя история». Фото и «Умный ассистент» FatSecret не реализуются (нужен платный ИИ).
- Экран «Завтрак ▾» (приём переключается): поиск и вкладки «История / Поиск еды / Рецепты».
  История — недавно в этом приёме и всё остальное, с последней порцией и РСК; «+» добавляет в один тап.
  Поиск — умный (морфология, синонимы, опечатки, частичное совпадение), приоритет: история и мои продукты →
  встроенная база (234 продукта USDA с русскими названиями + 22 типовых блюда) → офлайн-база российских
  товаров (3 062 товара Open Food Facts). Рецепты — мои рецепты, типовые блюда («Изменить под себя» создаёт
  свой рецепт с теми же ингредиентами), мои продукты.
- Экран порции: КБЖУ на 100 г, масса, кнопки «как в прошлый раз» и 50–250 г, пересчёт, расширенные
  нутриенты порции (раскрывающийся блок), источник данных.
- Штрихкод: свой каталог → офлайн-база → Perek.us (если есть сервер) → Open Food Facts онлайн. Неполные
  данные открывают форму продукта с подставленными значениями.
- Расширенные нутриенты (необязательные): сахара (всего), добавленный сахар, клетчатка, жиры насыщенные /
  моно- / полиненасыщенные / транс, омега-3, холестерин, натрий (соль), калий, кальций, железо, магний,
  витамин D. Нет данных ≠ 0.
- Статистика «Что я съел сегодня / За неделю»: калории и БЖУ к целям, белок и углеводы в г/кг веса,
  белок по приёмам пищи, вода, нутриенты с покрытием данных («≥ X, данные по N% калорий», «мало данных»),
  неделя — калории по дням с линией цели, средние по дням с записями.
- Личный план («Составить личный план»): пол, год рождения, рост, нагрузка; цель — поддержание или вес
  к дате (вручную или из соревнования вкладки «Сезон»: целевая масса и день взвешивания); белок г/кг, доля
  жиров; расчёт по Миффлину — Сан Жеору; предупреждения о темпе > 1%/нед, калорийность не ниже основного
  обмена, углеводы < 3 г/кг. Вкладка «Вес» — ежедневный вес, график 90 дней, изменение за неделю, до цели
  (записи общие с «Сезоном»). Вкладка «Вода» — цель EFSA или своя, особые дни по назначению специалиста.
- Вода: +стакан 250 мл / бутылка 0,5 л / литр / своё, прогресс к цели дня.
- Свой каталог продуктов: название, бренд, КБЖУ на 100 г или 100 мл, источник сведений, ссылка, штрихкод.
  Проверка обязательных полей, отрицательных значений, суммы БЖУ > 100 г на 100 г; мягкое предупреждение
  при расхождении калорий с БЖУ.
- Запись хранит снимок пищевой ценности: правка или удаление продукта не меняет историю.
- Рецепты из продуктов каталога; при ингредиентах в мл обязательна итоговая масса блюда.
- Поиск Perek.us по названию и штрихкоду через локальный сервер, с подтверждением продукта пользователем,
  предупреждением о неточном совпадении и ссылкой «Данные: perek.us». Найденный продукт сохраняется
  в свой каталог и дальше доступен офлайн. Без ключа функция аккуратно отключена.
- Штрихкод: ручной ввод EAN-8/EAN-13 с проверкой контрольной цифры; сначала поиск в своём каталоге
  (офлайн), затем Perek.us. Сканирование камерой (ZXing) — только на HTTPS или localhost.

**Тренировки** (v0.5 — по образцу интерфейса приложения Shagulin; этап 2 плана)
- Пять разделов: «Неделя», «Программы», «Упражнения», «Журнал», «Замеры». Плашка «Идёт тренировка» с таймером
  видна, пока тренировка не сохранена.
- Каталог упражнений: 83 встроенных (кардио, зал по группам мышц, хват, скоростно-силовые, борьба:
  набегания, броски, встречи в партере и в стойке, учебные схватки, акробатика, разбор) и свои. Раздела
  «Разминка» нет (v0.5.1, решение пользователя). Группы-фильтры, поиск, последний результат справа.
  Иконка: у 40 упражнений зала — рисунок позы Everkinetic (CC BY-SA 4.0), у 10 кардио — собственные
  пиктограммы поз с подсвеченными работающими частями тела (v0.7), у остальных и у своих — анатомическая
  схема мышц (Wikimedia Commons / wger, CC BY-SA 3.0; основные красные, вспомогательные светлые).
  На странице упражнения — рисунок позы или пиктограмма и анатомическая схема спереди и сзади. Видео техники — в следующих версиях.
- Тип измерения подхода: вес × повторения, повторения, время, расстояние и время, встречи по времени,
  отметка «сделано» (разминка, разбор).
- Программы — сколько угодно: название («Ковёр — Пн, Ср, Пт», «Качалка — Вт, Чт»), формат (по упражнениям /
  тренировка на ковре / день борьбы), вид спорта, дни недели (только подпись), значок, цвет, своё фото обложки.
  Для ковра и дня борьбы создаётся стартовый план (день борьбы: 2 встречи в партере, 6 встреч в стойке
  по 3 мин, разбор; ковёр: отработка техники), его можно менять. Пункт программы: подходы/встречи, повторения «от–до», вес, время, отдых, заметка.
- «Неделя»: на каждый день — утро, день, вечер; программа ставится в план и запускается кнопкой «Начать»;
  выполненное отмечается по журналу; «Скопировать прошлую неделю».
- Экран тренировки (как в образце): обзор упражнений → экран упражнения с крупной иконкой, кнопками «Техника»,
  «История», «Заменить», подходами с галочкой, подсказкой «в прошлый раз», таймером отдыха (запускается
  галочкой, +15 с, «Пропустить»), заметкой и кнопкой «Далее». Черновик хранится в базе и переживает
  перезагрузку. Для ковра и дня борьбы — поле «Над чем работал». Завершение: название, время начала (можно
  записать прошедшую тренировку), длительность, тяжесть 1–10, «Разбор, дневник». Сохраняются только подходы
  с галочкой (по желанию — и неотмеченные со значениями).
- Журнал: все тренировки, правка (через тот же экран), удаление, «Сохранить как программу».
- Замеры: общие тесты (подтягивания — максимум и за минуту, отжимания, брусья, максимумы в жиме, приседе и
  становой, канат без ног, прыжок с места, бег 30 м и 3 км, пресс за минуту, вис на перекладине и на кимоно,
  кистевой динамометр, обхваты предплечий и шеи) и свои тесты. Нормативов и оценок нет — только своя динамика:
  последний, лучший, изменение к прошлому, график. Фото прогресса — хранятся в приложении на устройстве,
  открываются без интернета, в резервную копию не входят.
- Старые шаблоны (до v0.5) автоматически превращены в программы.

**Восстановление — готовность** (v0.8, по мотивам Athlytic, Bevel, Training Today, NOOP, openGym):
- Утренний чек-ин (до 30 с): часы сна (подсказка из записи сна дня), качество сна, энергия, настроение,
  стресс (1–5), что болит — нажатием на карте мышц или кнопками групп; по желанию пульс покоя и HRV (RMSSD,
  показывается и ln(RMSSD)). Одна запись на день.
- Оценка готовности 0–100 относительно личной нормы (медиана последних до 28 чек-инов); пока прошлых
  чек-инов меньше M (по умолчанию 7) — «Калибровка: N из M дней». Стартовые веса: сон 30%, энергия/настроение/
  стресс 25%, боль 25%, пульс/HRV 20%; нет данных — вес распределяется на остальные, нет ничего — «Недостаточно
  данных». Статус над числом, полоса, «Что влияет» (2–4 плитки с отклонением от нормы и стрелкой),
  фраза-объяснение, совет на сегодня с кнопками «К тренировке на сегодня» и «Настроить». Совет не меняет план.
  Пометка «Не медицинская рекомендация». Все стартовые числа настраиваются («Настроить»).
- Карта мышц в оттенках серого: «Усталость» (свежая / восстанавливается / утомлена) или «Нагрузка» (подходы
  за 7 дней), штриховка — «болит»; легенда. Усталость по журналу: подходы × близость к отказу (RPE) со спадом
  за 48 ч (малые группы) / 72 ч (крупные). Нажатие на группу — последняя тренировка, объём за неделю, «болит».
- История: 7 / 30 дней — готовность, сон, мышечная боль; нажатие на день — его чек-ин, сон и тренировки.
- Связи: в «Тренировках» — строка с готовностью и восстанавливающимися группами; в «Питании» при готовности
  ниже 60 — мягкое напоминание про воду и белок без цифр; в «Сезоне» — средняя готовность по неделям и
  «усталость / форма» по нагрузке (минуты × тяжесть).

**Восстановление — сон** — крупная карточка сна (v0.6): «Лёг спать», идущий сон с таймером и «Проснулся», или ручной
ввод времени; полоса 14 дней с отмеченными записями; графики «время в постели» (столбики, среднее) и
самооценок (выбор показателя) за 2 недели / 30 / 90 дней; оценки засыпания и ночных
пробуждений; самочувствие, усталость, болезненность мышц, желание тренироваться (шкалы 1–5, необязательны).
Показывается «время в постели»; «оценка сна» — только если введены оценки засыпания/пробуждений, с
пояснением, что это оценка пользователя. Фазы сна не вычисляются. Тенденции: средние последних 7 записей
против предыдущих 7, с оговоркой, что это не диагноз.

**Сезон** — крупная карточка ближайшего старта (v0.6): дни до старта, взвешивание, цель, текущая масса и
разница; соревнования (вид спорта, категория, название, старт, место, взвешивание, целевая масса,
статус, регламент, заметки), фильтр дзюдо/самбо, предстоящие и прошедшие. Взвешивание — отдельное поле;
кнопка подставляет «за день до старта», но не автоматически. Масса тела: последняя запись, изменение за неделю,
до цели, график 30/90 дней/всё с линией целевой массы ближайшего старта, история. Цель никогда не меняется автоматически.

**Ещё**
- Добавки: журнал (название, доза, единица, даты, цель, заметки, источник). Без рекомендаций и назначений.
- Библиотека источников: название, автор, URL, даты публикации и проверки, тема, тип (обзор, метаанализ,
  исследование, рекомендация, опыт тренера и т. д.), заметки.
- Сводка для ИИ: выбор разделов и периода, шаблоны «Анализ тренировки», «Недельный обзор
  восстановления», «Разбор питания», редактируемый текст, копирование кнопкой. Ничего не отправляется.
- Резервная копия: экспорт всего в JSON; импорт с полной проверкой, сводкой и подтверждением,
  режимы «объединить» и «заменить».
- Настройки: параметры, состояние хранилища (запрос постоянного хранения), статус сети и Perek.us.

**Офлайн** — после первой загрузки по localhost/HTTPS оболочка открывается без сети (Service Worker);
все дневники и расчёты работают локально.

## Не входит в v0.1

Аккаунты и несколько спортсменов, синхронизация и серверное хранение, Apple Health / Apple Watch,
нативное iOS-приложение, публикация, платные API ИИ, распознавание еды по фото, автоматический поиск
соревнований, автоматическая генерация тренировочных планов, научный поиск и оценка доказательности,
адаптер Open Food Facts. См. `ROADMAP.md`.

## Принципы безопасности рекомендаций

- Приоритет систематических обзоров, метаанализов, качественных исследований и официальных рекомендаций;
  опыт бойцов — практический материал, не доказательство.
- Не придумывать публикации, ссылки, результаты и статистику; показывать ограничения данных.
- Никаких автоматических назначений лекарств, витаминов, добавок; никакого опасного обезвоживания
  и резкого ограничения питания ради взвешивания.
- Личные данные и ключи не публикуются; приложение не разворачивается публично без разрешения.
