# Требования к продукту — Personal Athlete OS v0.1

## Назначение

Личное приложение одного спортсмена (дзюдо и самбо) для ежедневного учёта подготовки. Главный принцип —
функциональность и надёжность, а не демонстрация технологий. Рабочее название может измениться.

## Параметры

| Параметр | Значение |
|---|---|
| Язык интерфейса | русский |
| Регион продуктов и соревнований | Россия |
| Часовой пояс | `Europe/Moscow` (`src/config.ts`) |
| Дзюдо | категория по умолчанию −73 кг |
| Самбо | категория по умолчанию −71 кг |
| Пользователи | один человек, без аккаунтов |
| Бюджет | без обязательных платных сервисов |

## Реализовано в v0.1

**Главная** — дата (по Москве), калории и БЖУ за сегодня, ближайшее соревнование с отсчётом дней и временем
взвешивания, три последние тренировки, последняя запись сна, последняя масса, быстрые действия. Только
реальные локальные данные; при их отсутствии — подсказки.

**Питание** (v0.4 — по скриншотам FatSecret пользователя; этап 1 плана «Питание → Тренировки → Восстановление → Сезон»)
- Дневник: полоса недели (дни с записями отмечены), итоги «Жиры / Углев / Белк / РСК / Калории» (РСК — % от
  цели калорий личного плана, «из …» — цели), плашки «Завтрак / Обед / Ужин / Перекус». Тап по всей плашке
  открывает шторку добавления. Записи: тап — правка, корзина — удаление. Карточка «Вода».
- Шторка: поиск, «Сканирование штрихкода», «Ручной ввод продукта», «Быстрый ввод калорий» (без продукта),
  «Моя сохранённая еда», «Моя история». Фото и «Умный ассистент» FatSecret не реализуются (нужен платный ИИ).
- Экран «Завтрак ▾» (приём переключается): поиск и вкладки «История / Поиск еды / Рецепты».
  История — недавно в этом приёме и всё остальное, с последней порцией и РСК; «+» добавляет в один тап.
  Поиск — умный (морфология, синонимы, опечатки, частичное совпадение), приоритет: история и мои продукты →
  встроенная база (234 продукта USDA с русскими названиями + 22 типовых блюда) → офлайн-база российских
  товаров (3 062 товара Open Food Facts). Рецепты — мои рецепты, типовые блюда («Изменить под себя» создаёт
  свой рецепт с теми же ингредиентами), мои продукты.
- Экран порции: КБЖУ на 100 г, масса, кнопки «как в прошлый раз» и 50–250 г, пересчёт, расширенные
  нутриенты порции (раскрывающийся блок), источник данных.
- Штрихкод: свой каталог → офлайн-база → Perek.us (если есть сервер) → Open Food Facts онлайн. Неполные
  данные открывают форму продукта с подставленными значениями.
- Расширенные нутриенты (необязательные): сахара (всего), добавленный сахар, клетчатка, жиры насыщенные /
  моно- / полиненасыщенные / транс, омега-3, холестерин, натрий (соль), калий, кальций, железо, магний,
  витамин D. Нет данных ≠ 0.
- Статистика «Что я съел сегодня / За неделю»: калории и БЖУ к целям, белок и углеводы в г/кг веса,
  белок по приёмам пищи, вода, нутриенты с покрытием данных («≥ X, данные по N% калорий», «мало данных»),
  неделя — калории по дням с линией цели, средние по дням с записями.
- Личный план («Составить личный план»): пол, год рождения, рост, нагрузка; цель — поддержание или вес
  к дате (вручную или из соревнования вкладки «Сезон»: целевая масса и день взвешивания); белок г/кг, доля
  жиров; расчёт по Миффлину — Сан Жеору; предупреждения о темпе > 1%/нед, калорийность не ниже основного
  обмена, углеводы < 3 г/кг. Вкладка «Вес» — ежедневный вес, график 90 дней, изменение за неделю, до цели
  (записи общие с «Сезоном»). Вкладка «Вода» — цель EFSA или своя, особые дни по назначению специалиста.
- Вода: +стакан 250 мл / бутылка 0,5 л / литр / своё, прогресс к цели дня.
- Свой каталог продуктов: название, бренд, КБЖУ на 100 г или 100 мл, источник сведений, ссылка, штрихкод.
  Проверка обязательных полей, отрицательных значений, суммы БЖУ > 100 г на 100 г; мягкое предупреждение
  при расхождении калорий с БЖУ.
- Запись хранит снимок пищевой ценности: правка или удаление продукта не меняет историю.
- Рецепты из продуктов каталога; при ингредиентах в мл обязательна итоговая масса блюда.
- Поиск Perek.us по названию и штрихкоду через локальный сервер, с подтверждением продукта пользователем,
  предупреждением о неточном совпадении и ссылкой «Данные: perek.us». Найденный продукт сохраняется
  в свой каталог и дальше доступен офлайн. Без ключа функция аккуратно отключена.
- Штрихкод: ручной ввод EAN-8/EAN-13 с проверкой контрольной цифры; сначала поиск в своём каталоге
  (офлайн), затем Perek.us. Сканирование камерой (ZXing) — только на HTTPS или localhost.

**Тренировки** — дзюдо, самбо, зал, другое; дата и время, название/цель, длительность, тяжесть (1–10),
заметки; упражнения с подходами (повторы, вес, отдых, RPE, заметки — всё необязательно). История,
справочник упражнений (создаётся автоматически по названию, без дублей), шаблоны (вручную или из
тренировки, запуск тренировки по шаблону), прогресс упражнения: максимальный вес, подходы, тоннаж, график.

**Восстановление** — кнопки «Лёг спать»/«Проснулся» или ручной ввод времени; оценки засыпания и ночных
пробуждений; самочувствие, усталость, болезненность мышц, желание тренироваться (шкалы 1–5, необязательны).
Показывается «время в постели»; «оценка сна» — только если введены оценки засыпания/пробуждений, с
пояснением, что это оценка пользователя. Фазы сна не вычисляются. Тенденции: средние последних 7 записей
против предыдущих 7, с оговоркой, что это не диагноз.

**Сезон** — соревнования (вид спорта, категория, название, старт, место, взвешивание, целевая масса,
статус, регламент, заметки), фильтр дзюдо/самбо, предстоящие и прошедшие. Взвешивание — отдельное поле;
кнопка подставляет «за день до старта», но не автоматически. Масса тела: история, график, линия целевой
массы ближайшего старта. Цель никогда не меняется автоматически.

**Ещё**
- Добавки: журнал (название, доза, единица, даты, цель, заметки, источник). Без рекомендаций и назначений.
- Библиотека источников: название, автор, URL, даты публикации и проверки, тема, тип (обзор, метаанализ,
  исследование, рекомендация, опыт тренера и т. д.), заметки.
- Сводка для ИИ: выбор разделов и периода, шаблоны «Анализ тренировки», «Недельный обзор
  восстановления», «Разбор питания», редактируемый текст, копирование кнопкой. Ничего не отправляется.
- Резервная копия: экспорт всего в JSON; импорт с полной проверкой, сводкой и подтверждением,
  режимы «объединить» и «заменить».
- Настройки: параметры, состояние хранилища (запрос постоянного хранения), статус сети и Perek.us.

**Офлайн** — после первой загрузки по localhost/HTTPS оболочка открывается без сети (Service Worker);
все дневники и расчёты работают локально.

## Не входит в v0.1

Аккаунты и несколько спортсменов, синхронизация и серверное хранение, Apple Health / Apple Watch,
нативное iOS-приложение, публикация, платные API ИИ, распознавание еды по фото, автоматический поиск
соревнований, автоматическая генерация тренировочных планов, научный поиск и оценка доказательности,
адаптер Open Food Facts. См. `ROADMAP.md`.

## Принципы безопасности рекомендаций

- Приоритет систематических обзоров, метаанализов, качественных исследований и официальных рекомендаций;
  опыт бойцов — практический материал, не доказательство.
- Не придумывать публикации, ссылки, результаты и статистику; показывать ограничения данных.
- Никаких автоматических назначений лекарств, витаминов, добавок; никакого опасного обезвоживания
  и резкого ограничения питания ради взвешивания.
- Личные данные и ключи не публикуются; приложение не разворачивается публично без разрешения.
