# Проверки

## Команды

| Команда | Что делает |
|---|---|
| `npm run check` | всё ниже по очереди; обязательна перед завершением любой задачи |
| `npm run typecheck` | TypeScript (strict) для интерфейса и для сервера |
| `npm run lint` | ESLint |
| `npm test` | Vitest, однократно (`npm run test:watch` — в режиме наблюдения) |
| `npm run build` | production-сборка с Service Worker в `dist/` |

## Ручная проверка в браузере (выполнена 22.10.2026, встроенный браузер Claude, Chromium)

Через `npm run build` + `npm start`, http://localhost:8787:
- продукт: пустая форма → ошибки полей; отрицательные жиры → «Не может быть отрицательным»; сохранение;
- приём пищи 80 г → 274 ккал, итоги дня; рецепт 100 г крупы / 250 г блюда → 137 ккал на 100 г;
- соревнование самбо: категория сменилась на −71, взвешивание не подставилось само, подсказка сработала;
- две записи массы → график с линией цели;
- тренировка с упражнением и двумя подходами, шаблон из тренировки, прогресс (тоннаж 1025 кг);
- «Лёг спать» → «Проснулся», ошибка при пробуждении не позже сна, шкалы 1–5, снятие выбора;
- добавка: ошибки дат и ссылки, удаление с подтверждением и отменой;
- экспорт копии (скачивание перехвачено в странице), удаление записи, импорт «объединить» вернул её;
  повреждённая копия отклонена с понятной ошибкой;
- сводка для ИИ: только выбранные разделы;
- **сервер остановлен** → страница открылась из Service Worker, записи читаются, новая запись питания
  сохранилась, вкладка Perek.us показывает понятное сообщение;
- ширина 375 px: нижнее меню, диалоги снизу, таблица подходов без горизонтальной прокрутки.

Не проверялось: реальный iPhone/Safari, режим «В самолёте» (проверялась недоступность сервера при
работающей сети браузера), сканирование камерой, реальные ответы Perek.us с ключом, копирование в буфер
обмена (кнопка не нажималась, чтобы не менять буфер пользователя).

## Как проверять дальше

- Новая логика → unit-тест рядом в `*.test.ts`.
- Изменение структуры данных → тест миграции в `repo.test.ts`/`backup.test.ts`.
- Изменение интерфейса → проверка в браузере на 375 px и на широком экране.
- Подключение ключа Perek.us → вручную: поиск «кефир», штрихкод с упаковки, несуществующий EAN.
