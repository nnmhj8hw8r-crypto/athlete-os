# Гладиатор: шахматки

Офлайн-приложение для секретаря внутриклубных соревнований по самбо клуба «Гладиатор».
Взвешивание → автоматическая разбивка на сетки по 3–5 человек → распределение по коврам →
печать шахматок по образцу клуба (одна на лист A4).

## Как пользоваться

1. Скопируйте `dist/gladiator.html` на компьютер (можно на флешку) и откройте двойным кликом
   в Chrome или Edge. Интернет не нужен.
2. Вкладка «Турнир»: дата, число ковров, части (годы рождения, формат борьбы, весовые категории).
3. «Взвешивание»: вводите участников, Enter — сохранить. Каждый сразу попадает в свою часть.
4. «Сетки»: «Собрать сетки» для части. Правки: перенос между сетками, «закрепить», своя подпись категории.
5. «Ковры»: проверить нагрузку, перенести сетку на другой ковёр.
6. «Печать»: выбрать шахматки и напечатать (или «Сохранить как PDF»).

Данные сохраняются в браузере автоматически. Кнопка «Сохранить в файл» делает файл турнира
(.json) — его можно открыть на другом компьютере. Файлы с реальными данными детей в Git не класть.

## Правила разбивки (меняются по мере уточнений)

- Группы: пол → уровень → вес (в фиксированном режиме — ещё весовая категория «до X кг»).
- Внутри группы — сетки по 3–5 человек с минимальной разницей в весе; хвостов из 1–2 человек нет.
  Слишком маленькая группа объединяется с соседним уровнем того же пола (карточка сетки предупредит).
- Подпись категории на бланке: фиксированный режим — граница категории; плавающий — вес самого
  тяжёлого, округлённый вверх. Несколько сеток с одним числом в части получают буквы: 24а, 24б…
- Внутри сетки — все со всеми; порядок кругов для 4 человек как на бланке клуба (1–2, 4–3 / 1–3, 2–4 / 1–4, 3–2).
- Ковры — поровну по числу схваток (3 чел. = 3, 4 = 6, 5 = 10).
- Опоздавший после разбивки встаёт в подходящую сетку с местом; если места нет — пересобирается
  только его группа. Изменённые напечатанные шахматки помечаются «перепечатать».

## Разработка

- `src/logic.js` — вся логика (без интерфейса), `src/app.js` — интерфейс, `src/style.css` — стили и бланк печати.
- `node gladiator/build.mjs` — собрать `dist/gladiator.html` (и `dist/artifact.html` для онлайн-демо).
- `node --test gladiator/tests/run-tests.mjs` — проверки логики.
- Требования и открытые вопросы — в документе проекта «Гладиатор — приложение для шахматок».
